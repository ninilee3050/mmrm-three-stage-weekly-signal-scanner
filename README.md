# MMRM 3단계 주봉 시나리오 추적 스캐너

기존 MMRM 조건을 1차 관찰 신호로 사용하고, 이후 5·20·50주선으로 2차·3차 신호를 추적하는 Python/Tkinter 프로그램입니다.

이 프로젝트는 [MMRM 주봉 매수포인트 검증 GUI](https://github.com/ninilee3050/mmrm-weekly-buy-candidate-scanner)를 바탕으로 만든 독립적인 3단계 시나리오 추적 버전입니다.

이 프로그램은 자동매매나 주문 프로그램이 아닙니다. 신호 탐지, 상태 추적, 과거 결과 확인을 위한 도구입니다.

## 핵심 기능

### 선택 종목 과거 기록

티커를 검색하면 최신 Yahoo 일봉을 다시 내려받아 월요일 시작 주봉으로 변환하고 전체 3단계 사이클을 계산합니다.

표시 컬럼:

- 1차신호일
- 2차신호일
- 3차판정일
- 결과
- 3개월후 수익률
- 6개월후 수익률
- 9개월후 수익률
- 12개월후 수익률

수익률은 3차 매수 신호 종가 대비 13·26·39·52주 후 종가 변화율입니다.

- 기간 미도달: `진행 중`
- 기간 도달: 실제 수익률
- 실패 또는 아직 매수가 발생하지 않은 사이클: `해당 없음`
- 필요한 가격이 없는 경우: `데이터 없음`

종목을 다시 검색할 때 최신 데이터로 재계산하므로, 기간이 도달한 수익률도 자동 갱신됩니다.

`3단계 신호 과거 기록`은 결과를 빠르게 구분할 수 있도록 행 색상을 사용합니다. 2차 이격·구조 폐기는 주황색, 3차 실패는 빨간색으로 표시합니다. 매수 성공은 3개월 후 손익률을 기준으로 진행 중은 연한 초록색, 손실은 탁한 적갈색, 0%는 중립 회색, 0% 초과~10% 미만은 연한 초록색, 10% 이상~25% 미만은 중간 초록색, 25% 이상은 진한 초록색으로 표시합니다.

### 연동형 차트 미리보기

`3단계 신호 과거 기록`의 한 행을 더블클릭하면 별도의 주봉 차트 창이 열립니다. 개별 날짜가 아니라 선택한 시나리오 사이클 전체를 기준으로 다음 범위를 처음 표시합니다.

```text
시작: 1차 신호일 1년 전
종료: 3차 판정일 1년 후
```

2차에서 폐기된 사이클은 2차 종료일 1년 후까지, 아직 진행 중인 사이클은 최신 데이터까지 표시합니다. 1차부터 마지막 신호까지 1년 이상 걸렸다면 중간 기간을 자르지 않고 전부 보여 줍니다.

- 1차 신호: 초록색 세로선
- 2차 신호: 주황색 세로선
- 3차 판정: 빨간색 세로선
- 마우스 휠: 날짜 범위 확대·축소
- 마우스 드래그: 차트 좌우 이동
- 차트 더블클릭: 선택 사이클의 처음 표시 범위로 복귀
- `← 이전` / `다음 →`: 같은 종목의 바로 이전·다음 과거 시나리오로 이동
- 키보드 `←` / `→`: 위 버튼과 동일하게 과거 시나리오를 이동
- 마우스 십자선: 해당 주의 OHLC, 거래량, 이동평균, Momentum, MACD, RSI, MFI 표시

차트 상단에는 현재 기록 위치를 `5 / 22` 형식으로 표시합니다. 첫 기록에서는 `← 이전`, 마지막 기록에서는 `다음 →`가 자동으로 비활성화되며 끝에서 반대편으로 순환하지 않습니다. 차트에서 기록을 이동하면 `3단계 신호 과거 기록` 표도 같은 행을 선택하고 화면 안으로 자동 스크롤합니다. 반대로 표의 다른 행을 선택하면 열린 차트가 그 기록으로 바뀝니다.

선택 기록의 결과 오른쪽에는 저장된 3·6·9·12개월 손익률을 `3M +12.35% · 6M -4.50% · 9M 진행 중 · 12M 데이터 없음` 형식으로 표시합니다. 아직 기간이 지나지 않았거나 가격 데이터가 없는 경우 새 값을 추정하지 않고 과거 기록과 동일한 `진행 중`, `데이터 없음`, `해당 없음` 상태를 표시합니다.

십자선을 차트 위에서 움직이면 선택한 주의 수치가 인베스팅닷컴 방식처럼 각 패널 제목 옆에 표시됩니다. 가격 패널에는 OHLC와 5·20·50·150·200주선, 나머지 패널에는 거래량·Momentum·MACD·RSI·MFI의 해당 주 수치가 각각 표시됩니다. 차트를 처음 열었을 때나 마우스가 차트를 벗어나면 현재 화면에서 가장 오른쪽 주봉의 날짜와 수치를 유지합니다.

세로 십자선의 최하단 날짜축에는 선택한 주봉 날짜를 어두운 배경의 라벨로 표시합니다. 좌우 끝 주봉에서도 날짜 라벨이 차트 밖으로 잘리지 않도록 자동으로 위치를 보정합니다.

RSI와 MFI는 70을 과열 기준, 30을 침체 기준으로 사용합니다. 70선은 빨간 점선, 30선은 파란 점선, 중앙 50선은 초록 실선으로 표시합니다. 지표선은 양봉과 같은 빨간색을 사용합니다. 지표가 70을 넘은 구간은 70선과 지표선 사이를 연한 빨간색으로, 30 아래로 내려간 구간은 30선과 지표선 사이를 연한 파란색으로 채웁니다. 이동평균선은 `5주 녹색 / 20주 청록 / 50주 파랑 / 150주 진한 적갈·갈색 / 200주 분홍`으로 표시하며, 5주선부터 200주선까지 선 굵기가 단계적으로 굵어집니다. 다크모드에서는 150주선이 빨간 신호·양봉과 섞이지 않도록 선명한 구리빛 갈색을 사용합니다. 20주선은 흰 배경에서 에메랄드색으로 보이지 않도록 라이트모드에서 형광 시안색 `#00e5ff`, 다크모드에서 기존 청록색 `#00d4d8`을 사용합니다.

거래량·Momentum·MACD Histogram 막대는 양봉·음봉 색상을 차트 배경과 50% 혼합한 연한 빨강·파랑으로 통일합니다. Momentum과 MACD Histogram은 0선을 기준으로 한 굵은 막대로 표시합니다. MACD의 파란 Signal선과 거래량 50주 평균선은 가격 차트의 50주선과 같은 파란색을 사용하며, 거래량 50주 평균선의 굵기도 가격 50주선과 동일합니다.

휠 확대·축소는 한 번에 급격히 변하지 않도록 단계가 완만하게 설정되어 있습니다. 확대할 때 주봉 간격만 벌어지지 않고 캔들과 거래량·Momentum·MACD 막대 폭도 간격에 비례해 함께 넓어집니다.

주봉 캔들은 상승봉과 하락봉 모두 내부가 흰색인 빈 봉으로 표시하며, 상승봉은 빨간 윤곽선, 하락봉은 파란 윤곽선을 사용합니다.

차트 창을 열어 둔 상태에서는 다른 과거 기록 행을 한 번 클릭하면 같은 창이 해당 사이클로 즉시 바뀝니다. Top 100이나 스캐너의 다른 종목을 선택해 검색이 완료되면 같은 차트 창도 그 종목의 최신 사이클로 갱신됩니다. 종목 행을 더블클릭하면 차트 창이 닫혀 있어도 검색 완료 후 자동으로 열립니다.

이전·다음 기록으로 이동할 때는 종목 차트의 1·2·3차 신호선과 처음 표시 날짜 범위를 다시 맞춥니다. S&P 500 비교 차트가 열려 있다면 비교창을 닫거나 데이터를 다시 내려받지 않고 같은 날짜 범위와 새 신호 위치로 함께 갱신합니다.

차트 상단의 `S&P 500 비교 열기` 버튼을 누르면 같은 창의 오른쪽에 S&P 500 주봉 가격 차트가 펼쳐집니다. 비교 지수는 미국 대형주 시장의 대표 기준인 S&P 500 하나로 고정하며 Yahoo Finance 티커 `^GSPC`를 사용합니다.

- 왼쪽 종목 차트와 오른쪽 S&P 500 차트는 같은 날짜 범위를 표시합니다.
- 어느 차트에서 휠 확대·축소 또는 좌우 드래그를 해도 두 차트가 함께 움직입니다.
- 어느 차트에 마우스를 올려도 세로 십자선과 날짜가 양쪽 차트에 연동됩니다.
- S&P 500 차트에도 선택한 종목의 1·2·3차 신호일을 해당 신호 색상의 흐린 점선으로 표시합니다.
- S&P 500에도 종목 차트와 동일하게 가격·거래량·Momentum·MACD·RSI·MFI 패널과 5·20·50·150·200주 이동평균선을 표시합니다.
- 비교창을 열 때 기존 종목 차트 폭은 줄이지 않고 그 폭만큼 오른쪽으로 창을 확장합니다.
- S&P 500 데이터는 버튼을 처음 누를 때 백그라운드에서 불러오며 이후에는 열린 프로그램 안에서 재사용합니다.

### MMRM 시나리오 추적 스캐너

`3단계 통합 스캔` 버튼 한 번으로 다음 작업을 수행합니다.

1. 현재 미국 시가총액 Top 100에서 새로운 1차 신호를 찾습니다.
2. 저장된 활성 시나리오에서 2차 후보를 찾고 20·50주선 이격과 필요한 경우 50·200주선 구조를 판정합니다.
3. 2차 완료 종목에서 3차 매수 또는 실패를 판정합니다.
4. 다음 스캔을 위해 활성 상태를 자동 저장합니다.

1차 신호는 현재 Top 100에서 새로 찾습니다. 이미 활성화된 종목은 현재 Top 100에서 빠져도 2차 폐기, 매수 성공 또는 실패로 종료될 때까지 계속 검사합니다.

활성 상태 파일:

```text
outputs/mmrm_active_scenarios.csv
```

이 파일은 통합 스캔이 정상 완료될 때 자동 갱신됩니다. 데이터 조회에 실패한 활성 종목은 삭제하지 않고 `갱신 실패` 상태로 다음 스캔까지 보존합니다.

현재 Top 100 전체의 과거 종료 시나리오 스냅샷도 통합 스캔이 끝날 때 자동 갱신됩니다.

```text
outputs/mmrm_closed_scenarios.csv
```

이 파일은 매번 행을 단순 추가하지 않고 현재 Top 100의 계산 결과를 다시 조립합니다. `티커 + 1차신호일`을 기준으로 중복을 제거하며, 조회에 실패한 현재 Top 100 종목은 직전 저장 결과를 보존합니다.

스캔을 한 주 이상 건너뛴 경우에도 마지막 확인일 이후 발생한 2차·3차 신호를 다음 실행에서 `미확인 기간` 신호로 표시합니다.

## 화면 구조

검색창 오른쪽의 `다크 모드` 또는 `라이트 모드` 버튼으로 메인 화면과 차트 미리보기의 테마를 함께 전환할 수 있습니다. 선택한 테마는 `outputs/ui_settings.json`에 저장되어 다음 실행에도 유지됩니다. 다크모드는 Codex 화면과 비슷한 푸른 기 없는 중성 회색·차콜 계열이며, 표·탭·입력창·스크롤바와 차트 배경·격자·축·십자선·지표 채움색이 함께 변경됩니다. 신호선과 이동평균선의 의미 색상은 유지됩니다.

다크모드의 기본 글자는 순백색 대신 눈부심을 줄인 저대비 회색을 사용합니다. UI 글꼴은 한글 가독성이 좋은 `Noto Sans KR`을 우선 사용하고, 설치되어 있지 않으면 `Segoe UI`, `Malgun Gothic` 순서로 자동 대체합니다.

다크모드 스크롤바는 흰색 트랙을 표시하지 않고 표 배경과 같은 색으로 숨깁니다. 손잡이와 화살표만 낮은 대비로 남으며 마우스를 올리거나 드래그할 때 조금 밝아집니다. 드래그와 마우스 휠을 포함한 가로·세로 스크롤 기능은 그대로 유지됩니다.

- 왼쪽: 미국 시가총액 Top 100 목록
- 가운데: 선택 종목 검색, 시나리오 성과와 3단계 신호 과거 기록
- 오른쪽: 창 전체 높이를 사용하는 MMRM 시나리오 추적 스캐너

초기 창 너비는 가운데의 `3단계 신호 과거 기록` 전체 컬럼과 오른쪽 스캐너 탭 중 가장 넓은 표의 전체 컬럼이 한 번에 보이는 폭을 기준으로 계산합니다. 각 표의 컬럼도 제목과 실제 표시값 중 더 긴 쪽에 맞춰 자동 확장됩니다. 선택 종목 요약 문구는 가운데 영역 폭에 맞춰 자동 줄바꿈되며, 화면이나 사용자가 줄인 창이 더 좁을 때는 각 표의 가로 스크롤로 나머지 컬럼을 확인할 수 있습니다.

하단 스캐너 탭:

- `이번 스캔 신호`: 이번 주 또는 미확인 기간에 새로 확인된 1·2·3차 신호. 매수 검토가 필요한 3차 매수 성공을 맨 위에 두고 2차, 1차 순으로 표시하며 각각 빨강, 주황, 초록 행으로 구분합니다.
- `활성 시나리오`: 2차 또는 3차 신호를 기다리는 종목. 3차 신호 대기 종목을 먼저 표시하고 주황색, 2차 신호 대기 종목은 초록색으로 구분합니다. 3차 신호 대기 안에서는 2차신호일 최신순, 2차 신호 대기 안에서는 1차신호일 최신순으로 정렬하며 같은 날짜는 시가총액 순위가 높은 종목을 먼저 표시합니다.
- `이번 스캔 종료`: 이번 실행에서 2차 폐기, 매수 성공 또는 실패로 종료된 종목
- `종료 시나리오`: 현재 Top 100 전 종목의 과거 종료 사례. `현재 시총순위`는 과거 신호 당시 순위가 아니라 통합 스캔 시점의 최신 시가총액 순위입니다. 1차신호일 최신순으로 표시하고 같은 날짜는 현재 시총순위순으로 정렬합니다. 행 색상은 선택 종목의 과거 기록과 같은 성공·실패·폐기 기준을 사용합니다.
- `오류`: 재시도 후에도 데이터를 불러오지 못한 종목

스캐너 화면에는 종목, 단계·결과, 신호 날짜와 데이터 상태처럼 판단에 필요한 컬럼만 표시합니다. `이번 스캔 신호`와 `활성 시나리오`에는 빠른 참고를 위해 종목과 섹터의 3개월 승률을 `승률 (승리 건수/분석 표본)` 형식으로 함께 표시합니다. `Close`, 이동평균값과 `MA20_50이격률` 같은 진단용 데이터는 화면에서 숨기지만 내부 계산과 저장 CSV에는 그대로 보존합니다. 종료 표는 2차 폐기와 3차 판정을 공통 `종료일` 기준으로 정렬합니다.

표의 종목을 클릭하면 선택 종목 검색으로 연결됩니다.

## 신호 규칙

### 1차 신호

기존 MMRM 원본 포인트가 발생한 동일 주봉에서 다음 조건을 모두 만족해야 합니다.

```text
MA_150 > MA_200
MA_50 > MA_20
Close >= MA_5
```

추가 조건이 나중에 만족되더라도 원본 포인트를 뒤로 이동시키지 않습니다.

### 2차 신호

1차 신호 이후 기한 없이 기다리며 다음 조건을 모두 만족한 첫 주봉입니다.

```text
Close < MA_5
Close < Open
```

이 주봉을 2차 후보로 삼아 다음 이격률을 계산합니다.

```text
MA20·MA50 이격률 = (MA_20 / MA_50 - 1) × 100
```

```text
이격률 < 5%  → 단기 배열에 따라 정상 2차 또는 중기 구조 판정
이격률 >= 5% → 2차 이격 과다 폐기, 사이클 종료
```

경계값인 정확히 5.00%부터 폐기합니다. 이격률이 5% 미만이어도 2차 후보 당시 `MA20 > MA50`이면 `MA50 > MA200`을 추가로 요구합니다.

```text
MA20 > MA50 and MA50 > MA200  → 정상 2차 신호
MA20 > MA50 and MA50 <= MA200 → 2차 중기 구조 미충족 폐기
MA20 <= MA50                   → 50·200주선 추가 조건 없음
```

`MA50 == MA200`은 미충족입니다. 2차에서 폐기되어도 종목 자체를 제외하지 않으며, 이후 새로운 1차 신호가 나오면 독립된 새 사이클을 시작합니다.

### 3차 신호 또는 실패

2차 신호 이후 기한 없이 기다리며 다음 조건을 모두 만족한 첫 주봉을 판정합니다.

```text
Close > MA_5
Close >= Open
```

그 주봉에서:

```text
Close > MA_20  → 매수 성공
Close <= MA_20 → 실패
```

2차 폐기, 매수 성공 또는 실패로 종료된 다음에는 해당 종목에서 새로운 1차 신호가 나올 때 새 사이클을 시작합니다.

## 데이터 기준

- Yahoo 일봉을 내려받아 월요일 시작 주봉으로 직접 재구성합니다.
- Yahoo 원본 `1wk` 데이터는 사용하지 않습니다.
- 통합 스캔과 선택 종목 검색은 현재 주봉을 포함해 데이터를 새로 내려받습니다.
- 금요일 종가 전에 실행한 현재 주봉 신호는 장중 잠정 결과일 수 있습니다.
- 최종 판정 기준은 주봉 종가입니다.
- 사용자가 장중 신호를 이용하는 경우 종가 전에 신호가 사라질 수 있습니다.
- 장중 스캔 결과와 활성 상태는 실행 시점의 스냅샷으로 저장되며, 다음 스캔에서 최신 데이터로 전체 사이클을 다시 계산해 갱신합니다.
- 시가총액 Top 100은 [StockAnalysis의 미국 상장 종목 순위](https://stockanalysis.com/list/biggest-companies/)에서 조회합니다. 미국 소재 기업만이 아니라 미국 거래소 상장 종목을 포함합니다.
- 분야별 성과는 현재 Top 100 구성 종목의 과거 결과입니다. 과거 각 시점의 Top 100 구성 종목을 복원한 분석은 아닙니다.
- Yahoo와 다른 차트 서비스는 원천 데이터와 가격 보정 방식이 달라 봉과 지표 값이 일부 다를 수 있습니다.

## 종목·분야별 시나리오 성과 분석

통합 스캔은 현재 시가총액 Top 100 종목의 과거 3단계 시나리오를 함께 집계합니다. 이 분석은 신호를 탈락시키는 조건이 아니라, 종목과 분야의 과거 성과를 비교하기 위한 참고 기능입니다. 기존 1·2·3차 신호 계산식은 변경하지 않습니다.

선택 종목의 `3단계 신호 과거 기록` 위에는 다음 요약을 표시합니다.

- 섹터와 산업
- 종료 사이클과 3차 매수 도달 건수
- 매수 도달률
- 3·6·9·12개월 승률과 실제 계산 표본 수

하단의 `분야별 성과` 탭에서는 다음 기능을 제공합니다.

- 섹터별 또는 산업별 집계 전환
- 3·6·9·12개월 분석 기간 전환
- 분야별 종목 수, 종료 사이클, 매수 도달률, 승률, 평균·중앙 손익률
- 선택 분야 안에서 종합점수·승률·평균 손익률·매수 도달률 기준 종목 순위

`분야별 종합 성과` 표는 선택한 분석 기간의 승률이 높은 분야부터 표시하며, 승률이 같으면 분석 표본 수와 평균 손익률 순으로 정렬합니다.
- 순위의 종목을 클릭하여 해당 종목 과거 기록 조회

승률은 실제 3차 매수 성공 후 해당 기간의 손익률이 확정된 사례만 분모에 포함합니다. 진행 중이거나 데이터가 없는 사례는 제외하고, 0% 손익은 승리로 계산하지 않습니다. 작은 표본도 숨기지 않고 `100.0% (1/1)`처럼 분자와 분모를 함께 표시합니다.

분야 정보는 Yahoo 검색 API에서 조회하여 다음 파일에 캐시합니다. 조회에 실패한 종목은 추측하지 않고 `미분류`로 표시합니다.

```text
data/sector_classification.csv
```

통합 스캔 후 다음 분석 파일이 자동 갱신됩니다.

```text
outputs/mmrm_sector_performance.csv
outputs/mmrm_industry_performance.csv
outputs/mmrm_field_stock_rankings.csv
```

`스캔 저장하기`를 누르면 같은 분석 결과를 기준일이 포함된 파일명으로 다운로드 폴더에도 저장합니다.

## 설치 및 실행

Python 3.11 이상을 권장합니다. 프로젝트 폴더에서 가상환경을 만들고 패키지를 설치합니다.

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Windows에서는 설치 후 `실행하기.bat`을 더블클릭합니다.

직접 실행:

```bash
python app.py
```

화면 없이 통합 스캔:

```bash
python weekly_scan.py
```

이 명령은 Windows와 Linux 환경에서 실행할 수 있습니다.

GUI는 Tkinter를 사용합니다. 일부 Linux 배포판에서는 운영체제 패키지 관리자로 Tkinter를 별도 설치해야 합니다.

## GitHub Actions

`.github/workflows/weekly-scan.yml`은 미국 뉴욕 시간 기준 매주 금요일 16:30에 통합 스캔을 실행합니다. 수동 실행도 지원합니다.

- 직전 실행의 `outputs/mmrm_active_scenarios.csv`를 Actions 캐시에서 복원해 Top 100 밖으로 이탈한 활성 종목도 계속 추적합니다.
- 이번 실행의 활성 상태를 다시 캐시에 저장합니다.
- 날짜별 신호·활성·종료·오류 CSV를 30일 동안 아티팩트로 보관합니다.
- GitHub의 예약 실행은 서비스 상황에 따라 설정 시각보다 늦게 시작될 수 있습니다.

공개 저장소는 60일 동안 활동이 없으면 예약 워크플로가 자동 비활성화될 수 있습니다. 이 경우 Actions 화면에서 다시 활성화하거나 수동 실행합니다.

## 문제 해결

- `ModuleNotFoundError`가 나오면 가상환경이 활성화됐는지 확인하고 `python -m pip install -r requirements.txt`를 다시 실행합니다.
- Yahoo 또는 StockAnalysis 조회 오류는 외부 데이터 제공처의 일시적 응답 제한일 수 있습니다. 잠시 후 다시 실행합니다.
- 데이터와 결과 CSV는 저장소에 올리지 않도록 `.gitignore`에서 제외합니다. 필요한 결과는 프로그램의 저장 기능이나 Actions 아티팩트로 보관합니다.
