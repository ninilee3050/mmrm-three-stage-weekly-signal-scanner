# MMRM 3단계 관찰·매수 시나리오

이 문서는 기존 MMRM 매수포인트를 **1차 관찰 시작 신호**로 재정의하고, 이후 5·20·50주선을 이용해 2차 신호와 최종 3차 매수 신호를 찾는 개선 시나리오의 확정 명세이다.

이 문서를 프로그램 개발, 과거 신호 검증, 자동 테스트의 기준으로 사용한다.

용어와 지표 계산의 기본 정의는 [MMRM 주봉 차트 설정 및 용어 사전](mmrm-chart-setup-and-glossary.md)을 따른다.

---

## 1. 전략 목적

이 전략의 목적은 `50주선 > 20주선`인 단기 이동평균 역전 상태에서 기존 MMRM 신호로 회복 가능성이 있는 종목을 먼저 찾고, 이후 단기 이동평균이 수렴하는 구간에서 5주선 재돌파를 확인해 진입하는 것이다.

전체 흐름은 다음 세 단계로 구성한다.

| 단계 | 색상 | 의미 |
|---|---|---|
| 1차 신호 | 초록색 | 관찰종목 편입 |
| 2차 신호 | 주황색 | 종가가 5주선 아래에 있는 음봉과 20·50주선 이격 확인 |
| 3차 신호 | 빨간색 | 5주선 재상승과 20주선 위 종가를 확인한 최종 매수 |

1차 신호는 매수 신호가 아니다. 3차 신호만 최종 매수 신호이다.

---

## 2. 공통 판정 원칙

| 항목 | 원칙 |
|---|---|
| 차트 주기 | 주봉 |
| 공식 판정 가격 | 미국 금요일 종가 |
| 과거 신호 계산 | 마감된 과거 주봉과 실행 시점의 현재 주봉을 함께 계산 |
| 금요일 장중 스캔 | 실행 시점까지의 이번 주 데이터를 포함 |
| 장중 결과 | 실행 시점의 잠정 스냅샷 |
| 최종 판정 기준 | 미국 금요일 주봉 종가 |
| 2차·3차 대기 기한 | 제한 없음 |
| 종목별 동시 진행 사이클 | 한 개 |

금요일 장중에는 그 시점의 최신 가격을 임시 종가로 사용해 신호를 보여줄 수 있다. 그러나 장중 결과는 확정 신호가 아니다.

장중 임시 신호를 보고 사용자가 먼저 매수했으나 장 마감 전 조건이 무너지면, 공식 3차 신호는 발생하지 않은 것으로 처리한다. 장중 매수에 따른 결과는 사용자의 판단 영역이다.

## 3. 원본 MMRM 포인트

### 3-1. 원본 MMRM 관찰 시작

원본 MMRM 알고리즘은 다음 순서로 포인트를 찾는다.

1. 직전 주에는 `Signal > MACD`였고 이번 주에는 `MACD > Signal`이 되어 MACD 상승흐름시작이 발생한다.
2. 상승흐름시작 주의 MACD가 0 아래이거나, 이번 주 MACD가 0 위더라도 직전 주 MACD가 0 아래이면 하락영역에서 시작된 상승흐름으로 인정한다.
3. 이때부터 MACD 상승흐름을 관찰한다.
4. MACD 상승흐름이 유지되는 동안 아래 세 조건이 처음 동시에 충족되는 주봉을 원본 MMRM 포인트로 정한다.

| 지표 | 조건 |
|---|---|
| Momentum | `Momentum > 0` |
| RSI | `RSI > 50` |
| MFI | `MFI > 50` |

세 조건 충족 전에 MACD 하락흐름시작이 발생하면 해당 관찰은 종료하고, 다음 하락영역 상승흐름시작을 기다린다.

### 3-2. 원본 포인트 날짜 고정 원칙

먼저 기존 MMRM 알고리즘만으로 원본 MMRM 포인트와 날짜를 확정한다. 그다음 **바로 그 날짜의 주봉**에 1차 신호 추가 조건을 적용한다.

추가 조건을 충족하지 못했다고 같은 MACD 흐름의 뒤쪽 주봉을 계속 검색해서 새로운 MMRM 포인트로 바꾸면 안 된다.

핵심 원칙:

> 이동평균 추가 조건은 원본 MMRM 포인트 날짜를 뒤로 미루는 조건이 아니라, 그 원본 포인트를 통과시키거나 폐기하는 고정 필터이다.

예를 들어 원본 MMRM 포인트가 발생한 주에 `MA50 <= MA20`이면 그 포인트는 폐기한다. 몇 주 뒤 `MA50 > MA20`이 되더라도 그 날짜를 같은 흐름의 새로운 1차 신호로 인정하지 않는다.

---

## 4. 1차 신호: 관찰종목 편입

원본 MMRM 포인트가 발생한 **동일한 주봉**에서 아래 조건을 모두 동시에 충족해야 1차 신호로 인정한다.

| 구분 | 조건 |
|---|---|
| 원본 조건 | 기존 MMRM 포인트 발생 |
| 장기 이동평균 | `MA150 > MA200` |
| 단기 이동평균 | `MA50 > MA20` |
| 5주선 위치 | `Close >= MA5` |

하나라도 충족하지 못하면 해당 원본 MMRM 포인트는 완전히 폐기한다.

### 4-1. 1차 신호 처리

| 상황 | 처리 |
|---|---|
| 네 조건 모두 충족 | 1차 신호 기록, 관찰종목 편입, 2차 신호 대기 |
| `MA150 <= MA200` | 원본 포인트 폐기 |
| `MA50 <= MA20` | 원본 포인트 폐기 |
| `Close < MA5` | 원본 포인트 폐기 |
| 폐기 후 같은 MACD 흐름에서 추가 조건 충족 | 1차 신호로 인정하지 않음 |
| 나중에 새로운 원본 MMRM 포인트 발생 | 그 새로운 날짜에서 1차 조건을 다시 판정 |

1차 신호는 `Close >= MA5`를 요구하므로 같은 주봉에서 `Close < MA5`인 2차 신호가 동시에 발생할 수 없다. 따라서 1차·2차 동시 신호 예외 규칙은 두지 않는다.

---

## 5. 2차 신호: 5주선 아래 음봉

1차 신호 이후에는 원본 MMRM 조건과 `MA150 > MA200`, `MA50 > MA20`의 지속 충족을 요구하지 않는다. 다만 2차 후보 주봉에서는 너무 늦은 진입을 제거하기 위해 `MA20`과 `MA50`의 이격률을 별도로 판정한다.

2차 신호는 1차 신호 다음 주부터 아래 두 조건이 처음 동시에 충족되는 주봉이다.

| 구분 | 조건 |
|---|---|
| 5주선 위치 | `Close < MA5` |
| 봉 방향 | `Close < Open` |

즉, 종가가 5주선 아래에 있고 음봉인 주봉을 2차 후보로 삼고, 아래 이격 기준을 통과해야 2차 신호로 기록한다.

### 5-1. 20·50주선 이격 판정

2차 후보 주봉에서 다음 식으로 이격률을 계산한다.

```text
MA20·MA50 이격률(%) = (MA20 / MA50 - 1) × 100
```

| 2차 후보 당시 상태 | 처리 |
|---|---|
| `MA20 <= MA50` | 정상 2차 신호, 3차 신호 대기로 전환 |
| `MA20 > MA50`이고 이격률 `< 5%` | 50·200주선 중기 구조 판정으로 이동 |
| `MA20 > MA50`이고 이격률 `>= 5%` | `2차 이격 과다 폐기`, 사이클 즉시 종료 |

경계값인 정확히 5.00%부터 폐기한다. 폐기된 사이클은 더 관찰하지 않으며, 해당 종목에서 이후 새 원본 MMRM 포인트가 발생해 1차 조건을 다시 충족해야 새 사이클을 시작한다.

이 판정은 2차 후보가 발생한 바로 그 주봉에서만 수행한다. 1차와 2차 사이에 일시적으로 `MA20 > MA50`이 되었는지는 따로 검사하지 않는다.

### 5-2. 50·200주선 중기 구조 판정

2차 후보에서 `MA20 > MA50`이고 이격률이 5% 미만인 경우에만 다음 조건을 추가로 검사한다.

| 2차 후보 당시 상태 | 처리 |
|---|---|
| `MA50 > MA200` | 초기 역전 또는 수렴 구간으로 허용, 정상 2차 신호 |
| `MA50 <= MA200` | `2차 중기 구조 미충족 폐기`, 사이클 즉시 종료 |

`MA50 == MA200`은 미충족이다. 반대로 2차 후보에서도 아직 `MA20 <= MA50`이면 이 추가 조건을 적용하지 않고 정상 2차 신호로 인정한다.

이 규칙은 `MA20 > MA50`으로 단기 배열이 이미 역전된 경우, 중기선인 50주선까지 200주선 아래에 있는 약한 장기 구조를 피하기 위한 것이다. 폐기는 해당 사이클에만 적용하며 종목을 영구 제외하지 않는다. 이후 이동평균 구조가 회복되고 새로운 1차 신호가 발생하면 완전히 독립된 새 사이클로 다시 관찰한다.

### 5-3. 상태 판정 방식

2차 신호는 직전 주와 비교하는 엄격한 교차 판정이 아니다.

- 직전 주 종가가 5주선 위였는지 확인하지 않는다.
- 이번 주에 처음 5주선 아래로 내려왔는지 확인하지 않는다.
- 5주선 아래에 머무는 동안 나중에 음봉이 나오면 그 음봉을 2차 신호로 인정한다.

| 상황 | 처리 |
|---|---|
| `Close < MA5`이고 음봉, `MA20 <= MA50` | 2차 신호 기록, 3차 신호 대기로 전환 |
| `Close < MA5`이고 음봉, 이격률 `< 5%`, `MA20 > MA50`, `MA50 > MA200` | 2차 신호 기록, 3차 신호 대기로 전환 |
| `Close < MA5`이고 음봉, 이격률 `>= 5%` | 2차 이격 과다 폐기, 관찰 종료 |
| `Close < MA5`이고 음봉, 이격률 `< 5%`, `MA20 > MA50`, `MA50 <= MA200` | 2차 중기 구조 미충족 폐기, 관찰 종료 |
| `Close < MA5`이지만 양봉 | 무시하고 2차 신호 계속 대기 |
| `Close < MA5`이지만 보합봉 | 무시하고 2차 신호 계속 대기 |
| `Close >= MA5` | 2차 신호 계속 대기 |

2차 신호 대기에는 기한을 두지 않는다. 2차 후보가 이격·중기 구조 기준을 통과하거나 둘 중 하나로 폐기될 때까지 기다린다.

## 6. 3차 신호: 최종 매수 또는 실패

2차 신호 이후에는 아래 조건으로 3차 후보를 찾는다.

| 구분 | 3차 후보 조건 |
|---|---|
| 5주선 위치 | `Close > MA5` |
| 봉 방향 | `Close >= Open` |

양봉뿐 아니라 보합봉도 3차 후보로 허용한다. 음봉은 허용하지 않는다.

### 6-1. 음봉 처리

2차 신호 이후 종가가 5주선 위로 올라왔더라도 음봉이면 3차 후보로 판정하지 않는다. 해당 주봉을 무시하고 다음 주를 계속 관찰한다.

직전 주 종가나 직전 주 5주선과 비교하는 엄격한 상승 교차 조건은 사용하지 않는다. 2차 신호 이후에 처음 나타나는 `Close > MA5`이면서 양봉 또는 보합봉인 주봉을 3차 후보로 본다.

### 6-2. 20주선 최종 판정

3차 후보가 발생하면 같은 주봉의 종가와 20주선을 비교한다.

| 조건 | 결과 |
|---|---|
| `Close > MA20` | 3차 신호 성공, 최종 매수, 사이클 종료 |
| `Close <= MA20` | 실패 포인트, 관찰 즉시 종료 |

`Close <= MA20`으로 실패한 뒤에는 같은 사이클을 더 관찰하지 않는다. 해당 종목에서 나중에 새로운 1차 신호가 발생해야 새 사이클을 시작한다.

3차 신호 대기에도 기한을 두지 않는다.

---

## 7. 1차 이후 유지하지 않는 조건

다음 조건은 1차 신호를 선별할 때만 사용한다.

- 기존 MMRM 조건
- `MA150 > MA200`
- `MA50 > MA20`
- `Close >= MA5`

1차 신호가 확정된 뒤에는 위 조건의 지속 충족을 요구하지 않는다. 단, 2차 후보가 발생한 주봉에서는 5% 이격 규칙과 조건부 `MA50 > MA200` 규칙을 별도로 적용한다.

2차 이격 기준을 통과한 뒤에는 3차 신호 시점에 `MA20 > MA50`으로 바뀌거나 이격이 5% 이상으로 커져도 허용한다. 3차 신호는 5주선, 봉 방향, 20주선 위치만으로 판정한다.

---

## 8. 종목별 사이클 관리

종목별로 한 번에 하나의 활성 사이클만 운영한다.

| 현재 상태 | 다음 처리 |
|---|---|
| 활성 사이클 없음 | 새로운 1차 신호를 받을 수 있음 |
| 1차 신호 후 2차 대기 중 | 중간에 발생한 새로운 1차 신호 무시 |
| 2차 신호 후 3차 대기 중 | 중간에 발생한 새로운 1차 신호 무시 |
| 2차 이격 과다 폐기 | 관찰 종료, 이후 새로운 1차 신호 대기 |
| 2차 중기 구조 미충족 폐기 | 관찰 종료, 이후 새로운 1차 신호 대기 |
| 3차 성공 | 매수 후 사이클 종료 |
| 3차 실패 | 관찰 종료 |
| 사이클 종료 후 | 이후 새로 발생하는 1차 신호부터 새 사이클 시작 |

3차 성공 후에는 보유 상태, 매도 조건, 추가매수 여부를 이 프로그램에서 추적하지 않는다. 매수 신호를 기록하면 해당 사이클은 끝난다.

---

## 9. Top 100과 관찰종목 범위

미국 시가총액 Top 100은 **새로운 1차 신호를 찾는 검색 범위**로 사용한다.

한번 1차 신호가 발생해 관찰종목으로 편입된 종목은 이후 시가총액 Top 100 밖으로 밀려나더라도 사이클이 끝날 때까지 계속 추적한다.

| 종목 상태 | Top 100 이탈 시 처리 |
|---|---|
| 아직 1차 신호가 없는 종목 | 새 1차 검색 대상에서 제외될 수 있음 |
| 1차 신호 후 2차 대기 | 계속 추적 |
| 2차 신호 후 3차 대기 | 계속 추적 |
| 2차 폐기 또는 3차 성공·실패 | 관찰목록에서 제거하고 종료 기록에 보존 |

## 10. 장중 잠정 신호와 종가 확정

### 10-1. 장중 스캔

미국 금요일 장중에 스캐너를 실행하면 실행 시점까지의 이번 주 OHLCV 데이터를 포함해 계산한다.

장중에 조건을 충족하면 화면과 저장 파일에는 실행 시점의 계산 결과가 그대로 반영된다. 프로그램은 장중 결과에 별도의 `(임시)` 접미사를 붙이지 않는다.

장중 스캔으로 갱신된 활성 상태는 실행 시점의 스냅샷이다. 이후 가격이 바뀌면 같은 주의 신호가 사라지거나 결과가 달라질 수 있으며, 다음 스캔은 최신 데이터를 다시 받아 전체 사이클을 재계산해 상태를 갱신한다.

### 10-2. 종가 확정

미국 금요일 종가가 확정된 후 같은 주봉을 다시 계산한다.

- 종가 기준으로 조건이 유지되면 해당 주의 최종 신호로 본다.
- 종가 기준으로 조건이 사라지면 장중에 관찰한 잠정 신호는 무산한다.
- 공식 매매 판단과 성과 해석은 금요일 종가가 확정된 결과를 기준으로 한다.

사용자가 장중 잠정 신호를 이용해 먼저 매매한 결과는 프로그램의 공식 신호 확정과 별개인 사용자 판단 영역이다.

## 11. 경계값 규칙

| 단계 | 비교 | 판정 |
|---|---|---|
| 원본 MMRM | `Momentum > 0` | 0은 미충족 |
| 원본 MMRM | `RSI > 50` | 50은 미충족 |
| 원본 MMRM | `MFI > 50` | 50은 미충족 |
| 원본 MMRM | `MACD > Signal` | 같으면 상승흐름 아님 |
| 1차 | `MA150 > MA200` | 같으면 미충족 |
| 1차 | `MA50 > MA20` | 같으면 미충족 |
| 1차 | `Close >= MA5` | 같으면 충족 |
| 2차 | `Close < MA5` | 같으면 미충족 |
| 2차 | `Close < Open` | 같으면 음봉이 아니므로 미충족 |
| 2차 이격 | `(MA20 / MA50 - 1) × 100 < 5%` | 정확히 5.00%부터 폐기 |
| 2차 중기 구조 | `MA20 > MA50`이면 `MA50 > MA200` | `MA50 == MA200`부터 폐기 |
| 3차 후보 | `Close > MA5` | 같으면 후보 아님 |
| 3차 후보 | `Close >= Open` | 같으면 보합봉으로 허용 |
| 3차 성공 | `Close > MA20` | 같으면 실패 |

## 12. 상태 저장과 기록

프로그램을 종료했다가 다시 실행해도 활성 관찰종목을 이어서 추적할 수 있어야 한다.

활성 상태에는 최소한 다음 정보를 저장한다.

- 순위, 티커, 회사명, 시가총액
- 1차 신호 날짜
- 현재 단계: 2차 대기 또는 3차 대기
- 2차 신호 날짜
- 마지막 확인일과 데이터 기준일
- 데이터 상태: 현재 주봉 포함, 확정 주봉, 갱신 실패

활성 상태는 `outputs/mmrm_active_scenarios.csv`에 저장한다. 2차 폐기 또는 3차 성공·실패로 종료된 사이클은 같은 스캔에서 활성 관찰목록에서 제거한다.

현재 Top 100 전체의 과거 종료 사례는 `outputs/mmrm_closed_scenarios.csv`에 저장한다. 통합 스캔 때마다 현재 Top 100의 전체 과거 사이클에서 종료 사례를 다시 조립하고 `티커 + 1차신호일`로 중복을 제거한다. 가격 조회에 실패한 현재 Top 100 종목은 직전 저장 결과를 보존한다.

종료된 사이클은 선택 종목 과거 기록을 불러올 때 전체 가격 데이터에서 다시 계산한다. 따라서 별도의 수동 편입 없이 1차·2차·3차 날짜와 결과가 바로 조회된다.

활성 종목의 데이터 조회가 실패하면 해당 상태를 삭제하지 않고 `갱신 실패`로 보존하여 다음 스캔에서 다시 시도한다.

## 13. 화면 기능 요구사항

화면 기능은 다음 세 부분으로 구성한다.

1. 미국 시가총액 Top 100 목록 조회
2. 선택 종목의 과거 신호 조회
3. MMRM 3단계 시나리오 추적 스캐너

선택 종목의 과거 신호 표는 세부 보조지표 대신 아래 컬럼만 표시한다.

1. `1차신호일`
2. `2차신호일`
3. `3차판정일`
4. `결과`
5. `3개월후 수익률`
6. `6개월후 수익률`
7. `9개월후 수익률`
8. `12개월후 수익률`

수익률은 3차 매수 신호 주봉 종가를 기준으로 각각 13주, 26주, 39주, 52주 뒤의 종가 변화율을 계산한다.

```text
향후 수익률(%) = (향후 주봉 종가 / 3차 신호 주봉 종가 - 1) × 100
```

2차 폐기와 실패 사이클은 실제 매수 신호가 아니므로 향후 수익률을 계산하지 않는다.

수익률 표시는 다음 규칙을 사용한다.

- 기간 미도달: `진행 중`
- 기간 도달: 실제 수익률
- 2차 폐기, 실패 또는 아직 매수가 발생하지 않은 사이클: `해당 없음`
- 필요한 가격이 없는 경우: `데이터 없음`

과거 기록 표는 결과를 빠르게 구분할 수 있도록 행 색상을 사용한다. 2차 이격·구조 폐기는 주황색, 3차 실패는 빨간색으로 표시한다. 매수 성공은 확정된 3·6·9·12개월 손익률 전체의 일관성과 확정 기간 수를 기준으로 표시한다.

- 4개 기간 모두 플러스: 가장 진한 초록색과 굵은 글씨
- 4개 중 3개 플러스: 중간 초록색
- 4개 중 2개 플러스: 중립 회색
- 4개 중 1개만 플러스: 연한 빨간색
- 4개 기간 모두 마이너스: 가장 진한 빨간색
- 확정 값이 없는 매수 성공: 진행 중을 나타내는 아주 연한 초록색

`진행 중`, `데이터 없음`, `해당 없음`은 수익·손실 개수에서 제외한다. 일부 기간만 확정된 경우에는 확정된 값들의 방향을 사용하되 1~2개 확정은 연한 색, 3개 확정은 중간색까지만 사용한다. 따라서 12개월까지 네 기간이 모두 확정된 지속 수익 사례만 가장 진한 초록색이 된다. 손실도 같은 방식으로 확정 기간이 많고 일관될수록 빨간색을 진하게 표시한다.

`3단계 통합 스캔` 버튼은 Top 100의 신규 1차 신호와 기존 활성 종목의 2차·3차 신호를 한 번에 검사한다.

스캐너 화면은 다음 탭으로 구성한다.

1. `이번 스캔 신호`: 이번 주 또는 마지막 확인 이후 발생한 1·2·3차 신호와 2차 폐기. 3차 매수 성공, 2차, 1차 순으로 우선 표시하고 단계별로 빨강, 주황, 초록 행을 사용한다. 같은 3차 매수 성공 안에서는 차트 강도 점수가 높은 종목을 먼저 표시한다.
2. `활성 시나리오`: 현재 2차 또는 3차를 기다리는 종목. 3차 신호 대기 종목을 먼저 표시하고 주황색, 2차 신호 대기 종목은 초록색으로 구분한다. 3차 신호 대기 안에서는 2차신호일 최신순, 2차 신호 대기 안에서는 1차신호일 최신순으로 정렬하며 같은 날짜는 시가총액 순위가 높은 종목을 먼저 표시한다.
3. `이번 스캔 종료`: 이번 실행에서 2차 폐기, 성공 또는 실패로 종료된 종목
4. `종료 시나리오`: 현재 Top 100 전 종목의 과거 종료 사례. `티커 + 1차신호일`로 중복을 제거하고 1차신호일 최신순, 같은 날짜는 현재 시총순위순으로 표시한다. `현재 시총순위`는 과거 1차신호 당시 순위가 아니라 통합 스캔 시점의 최신 시가총액 순위다. 선택 종목 과거 기록과 같은 성공·실패·폐기 색상을 사용한다.
5. `오류`: 재시도 후에도 데이터를 갱신하지 못한 종목

스캐너 화면에는 티커, 회사명, 섹터, 단계·결과, 신호 날짜와 데이터 상태처럼 판단에 필요한 컬럼만 표시한다. `이번 스캔 신호`와 `활성 시나리오`에는 종목과 섹터의 3개월 승률을 실제 승리 건수와 분석 표본 수를 포함해 표시한다. `MA_20`, `MA_50`, `MA_200`, `MA20_50이격률` 같은 진단용 값은 내부 계산과 저장 CSV에는 보존하지만 화면 표에서는 숨긴다. 종료 표에는 2차 폐기일과 3차 판정일을 함께 정렬할 수 있도록 공통 `종료일`을 둔다.

1차 신호는 현재 Top 100에서 찾는다. 이미 활성화된 종목은 Top 100에서 이탈해도 종료될 때까지 계속 검사한다. 스캔을 건너뛴 기간에 발생한 2차·3차 전환도 다음 실행에서 `미확인 기간` 신호로 표시한다.

## 14. 검증 사례

### 14-1. DE: 2차 신호는 엄격한 교차가 아님

| 날짜 | 내용 | 처리 |
|---|---|---|
| 2024-09-02 | 유효한 1차 신호 | 관찰 시작 |
| 2024-10-14 | `Close < MA5`이지만 양봉 | 무시, 2차 계속 대기 |
| 2024-10-21 | `Close < MA5`이고 음봉 | 2차 신호 |

이 사례는 처음 5주선 아래로 내려온 주가 양봉이면 무시하고, 이후 계속 5주선 아래에 있더라도 음봉이 처음 나오는 주를 2차 신호로 인정한다는 기준이다.

### 14-2. MS: 5주선 위 음봉은 3차 후보가 아님

| 날짜 | 내용 | 처리 |
|---|---|---|
| 2023-12-11 | 1차 신호 | 관찰 시작 |
| 2024-01-08 | 2차 신호 | 3차 대기 |
| 2024-03-04 | `Close > MA5`이지만 음봉 | 무시, 3차 계속 대기 |
| 2024-03-11 | 양봉, `Close > MA5`, `Close > MA20` | 3차 성공, 최종 매수 |

### 14-3. 원본 포인트를 뒤로 미루지 않음

AXP의 원본 MMRM 포인트가 2025-06-02에 발생했지만 그 주에 `MA50 > MA20`을 충족하지 못했다면 해당 포인트는 폐기한다.

몇 주 뒤 `MA50 > MA20`이 된 2025-07-14를 같은 MACD 흐름의 새로운 1차 신호로 바꾸면 안 된다.

### 14-4. 1차·2차 동시 신호를 만들지 않음

DELL 2025-06-09처럼 원본 MMRM 조건과 2차 형태가 같은 주에 보이더라도 `Close < MA5`이면 1차 신호의 `Close >= MA5` 조건을 충족하지 못한다.

따라서 해당 주의 원본 포인트를 폐기하며, 1차·2차 동시 신호로 기록하지 않는다.

### 14-5. PANW: 초기 역전은 허용하고 과도한 이격은 폐기

| 사례 | 1차 | 2차 후보 | 2차 당시 이격률 | 처리 |
|---|---|---|---:|---|
| PANW 2023 | 2023-02-06 | 2023-04-17 | 약 0.43% | 정상 2차 신호, 2023-05-08 3차 매수 성공 |
| PANW 2026 | 2026-04-27 | 2026-07-20 | 약 14.78% | 2차 이격 과다 폐기 |

두 사례 모두 2차 후보 당시 `MA20 > MA50`이지만 진행 정도가 다르다. 단순 역전 여부로 전부 폐기하지 않고, 5% 미만의 초기 역전은 허용하며 5% 이상 벌어진 경우만 늦은 신호로 폐기한다.

규칙 추가 전에 이미 3차 신호 대기로 저장되어 있던 사이클이 새 2차 폐기 기준에 걸리면 다음 통합 스캔에서 `규칙 재평가`로 폐기 기록을 남기고 활성 목록에서 제거한다.

### 14-6. MU: 약한 중기 구조는 폐기하되 이후 새 사이클은 허용

| 사이클 | 1차 | 2차 후보 | 2차 당시 핵심 배열 | 처리 |
|---|---|---|---|---|
| MU 2023 | 2023-04-10 | 2023-05-01 | `MA20 58.67 > MA50 58.33`, `MA50 58.33 <= MA200 63.23` | 2차 중기 구조 미충족 폐기 |
| MU 2025 | 2025-05-12 | 2025-07-14 | 회복된 배열에서 새 1차 신호로 시작 | 정상 2차, 2025-08-04 3차 매수 성공 |

MU 2023 사이클은 이후 상승했더라도 2차 후보 당시 50주선이 200주선 아래였으므로 새 규칙에서는 매수하지 않는다. 다만 이 폐기는 MU 종목 전체가 아니라 해당 사이클에만 적용한다. 이후 장기·중기 배열이 회복되고 2025-05-12에 새로운 원본 MMRM 포인트와 1차 조건이 동시에 충족되었으므로 독립된 새 사이클로 다시 관찰한다.

이 사례의 목적은 과거에 폐기된 종목을 영구 배제하지 않는 것이다. `사이클 폐기 → 새 1차 신호 대기 → 조건을 다시 충족하면 새 사이클 시작` 순서를 유지한다.

```text
        +-- Close > MA20  ------> [3차 성공·매수·사이클 종료]
        |
        +-- Close <= MA20 ------> [실패·관찰 종료]
```

필터를 통과하지 못한 원본 포인트, 진행 중인 사이클에서 다시 발생한 1차 신호, 2차·3차의 무시 대상 주봉은 상태를 변경하지 않는다. 단, 2차 후보가 이격 과다 또는 중기 구조 미충족이면 그 주에 사이클을 폐기하고 종료한다.

---

## 16. 최종 요약 공식

> **기존 MMRM 알고리즘으로 확정된 원본 포인트의 동일 주봉에서 `MA150 > MA200`, `MA50 > MA20`, `Close >= MA5`를 모두 충족하면 1차 관찰 신호로 편입한다. 이후 기한 없이 관찰하다가 `Close < MA5`인 음봉을 2차 후보로 잡는다. 이격률이 5% 이상이면 이격 과다로 폐기한다. 5% 미만일 때 `MA50 >= MA20`이면 정상 2차이며, `MA20 > MA50`이면 `MA50 > MA200`까지 충족해야 정상 2차로 인정하고 그렇지 않으면 중기 구조 미충족으로 폐기한다. 정상 2차 이후 `Close > MA5`인 양봉 또는 보합봉이 나오면 3차 후보로 판정하고, 같은 주 종가가 `MA20` 위이면 최종 매수, `MA20` 이하이면 실패로 종료한다.**

1차 이후에는 원본 MMRM 조건과 장기·단기 이동평균 배열의 지속 충족을 요구하지 않는다. 예외적으로 2차 후보 주봉에서 20·50주선 이격률과 필요한 경우 50·200주선 중기 구조를 판정한다. 최종 판정 기준은 금요일 종가이며, 장중 결과는 실행 시점의 잠정 스냅샷이다.

## 17. 종목·분야별 성과 분석

성과 분석은 현재 시가총액 Top 100 구성 종목의 과거 시나리오 결과를 집계한다. 과거 각 시점의 Top 100을 복원하는 방식이 아니며, 분석 기준일 화면에 현재 구성 종목 기준임을 표시한다.

이 기능은 참고 통계이며 1차·2차·3차 신호의 검색 조건이나 사전 탈락 조건으로 사용하지 않는다.

### 17-1. 종목별 지표

| 지표 | 계산 기준 |
|---|---|
| 종료 사이클 | 2차 폐기, 3차 실패, 3차 매수 성공으로 종료된 전체 사이클 |
| 매수 도달률 | 3차 매수 성공 건수 / 종료 사이클 수 |
| 기간별 분석 표본 | 3차 매수 성공 후 선택 기간의 손익률이 `확정`된 건수 |
| 기간별 승률 | 확정 손익률이 0%보다 큰 건수 / 기간별 분석 표본 |
| 평균·중앙·최고·최저 | 기간별 분석 표본의 확정 손익률 |

진행 중, 데이터 없음, 해당 없음 상태는 기간별 승률 분모에서 제외한다. 손익률이 정확히 0%인 사례는 분석 표본에는 포함하지만 승리로 계산하지 않는다. 표본 수가 적어도 결과를 숨기지 않고 `승률 (승리 건수/분석 표본)`을 함께 표시한다. 분석 표본이 0건이면 `미산출 (0건)`으로 표시한다.

### 17-2. 분야 집계와 종목 순위

종목은 섹터와 세부 산업으로 분류한다. 분야별 통계는 소속 종목의 확정 사례를 하나로 합쳐 계산하므로, 종목별 승률을 단순 평균하지 않는다.

선택 분야의 종합점수는 다음과 같이 계산한다.

```text
종합점수 = 분야 내 승률 백분위 점수 50% + 분야 내 평균 손익률 백분위 점수 50%
```

3·6·9·12개월마다 표본과 성과가 달라지므로 분석 기간을 바꾸면 대장주 순위도 다시 계산한다. 해당 기간의 확정 표본이 없는 종목은 순위를 부여하지 않고 목록 하단에 표시한다.

### 17-3. 분야 데이터 원칙

- Yahoo 분야 정보를 로컬 CSV에 캐시한다.
- 가져오지 못한 값은 임의로 추측하지 않고 `미분류`로 표시한다.
- 가격 데이터 오류 종목은 해당 통계에서 제외하고 제외 종목 수를 화면에 표시한다.
- 기존 스캔에서 계산한 종목별 사이클을 재사용하며 성과 분석을 위해 가격이나 신호를 다시 계산하지 않는다.

## 18. 3차 신호 차트 강도 연구 점수

차트 강도는 기존 1·2·3차 신호를 변경하는 조건이 아니다. 3차 매수 성공이 여러 개 발생했을 때 과거의 큰 상승 사례와 차트 모습이 더 가까운 종목을 먼저 검토하기 위한 연구용 상대점수다.

3차 신호 주봉에서 다음 다섯 값을 계산한다.

| 평가항목 | 계산 기준 |
|---|---|
| 52주 저점 대비 상승폭 | `(3차 종가 / 최근 52주 최저가 - 1) × 100` |
| 최근 26주 변동성 | 최근 26주 주간 종가 수익률의 표준편차를 연환산 |
| 최근 13주 수익률 | `(3차 종가 / 13주 전 종가 - 1) × 100` |
| Momentum | 기존 14주 Momentum을 3차 종가로 나눈 비율 |
| MFI | 기존 프로그램의 14주 MFI |

서로 단위가 다른 원값을 직접 더하지 않는다. 각 값을 과거 확정 MMRM 매수 성공 사례의 백분위로 바꾸고 다섯 백분위의 평균을 구한 뒤, 그 평균도 과거 복합점수 분포에서 다시 백분위로 변환한다.

```text
최종 차트 강도 >= 70점 → 우선검토
최종 차트 강도 < 70점  → 일반검토
```

70점은 12개월 수익 확률 70%라는 뜻이 아니다. 과거 비교분포의 약 70%보다 강한 차트 조합이라는 의미다. 70점 미만도 실패·폐기로 바꾸지 않으며 자동 매수나 자동 탈락에 사용하지 않는다.

프로그램은 연구 당시의 현재 시가총액 1~200위 확정 매수 성공 사례 2,175건에서 미래 수익률을 제외하고 다섯 특징과 `3차 신호일 + 52주` 사용 가능 날짜만 저장한 기준 스냅샷을 사용한다. 신규 신호를 평가할 때 그 신호일보다 사용 가능 날짜가 늦은 사례는 제외한다. 따라서 당시 알 수 없었던 미래 12개월 결과는 점수 계산에 들어가지 않는다.

`이번 스캔 신호`의 차트 강도 셀에 마우스를 올리면 다음 내용을 표시한다.

- 다섯 평가항목의 실제 값
- 각 항목의 과거 대비 백분위 점수
- 최종 점수와 검토등급
- 점수의 주된 강점과 상대적으로 약한 항목
- 비교에 사용된 과거 확정 사례 수

2020~2025 최근 Top100 검증에서는 전체 182건 중 70점 이상 70건을 골랐고, 12개월 +20% 이상 비율이 50.0%에서 70.0%로 높아졌다. 이 효과는 35개 후보를 고려한 다중검정 보정 후에도 유의했다. 비손실률은 77.5%에서 84.3%로 관찰상 개선됐지만 통계적으로 확정된 수준은 아니므로 수익 보장이나 손절 대체 수단으로 해석하지 않는다. 상세 연구 결과는 [MMRM 3차 신호 차트 강도 연구 점수](mmrm-profit-success-research.md)에 기록한다.

이 수치는 2020년 이전 확정 사례를 고정한 검증 결과다. 실전 프로그램은 각 신호일에 이미 결과가 확정된 사례를 추가하는 확장 기준을 사용하므로 과거 전체를 다시 점수화하면 70점 경계의 일부 사례가 달라질 수 있다. 현재 기준자료에서는 182건 중 `SCHW 2024-02-12` 한 건만 70점 아래로 이동했으며, 이는 미래정보 사용이 아니라 기준분포 갱신 방식의 차이다.

## 19. 이 문서에서 다루지 않는 범위

다음 내용은 이번 개발 범위에 포함하지 않는다.

- 매수 후 보유 기간
- 매도 조건
- 손절 조건
- 추가매수 조건
- 자금 배분
- 브로커 주문 연동
- 자동매매 실행

이 프로그램의 범위는 1차 관찰 신호부터 3차 최종 매수 신호 또는 실패 종료까지이다.
